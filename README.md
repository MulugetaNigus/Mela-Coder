# Mela-Coder

Autonomous CLI coding agent powered by the Mela AI text generation API.

## Usage

```bash
npm install
npm run build
npm start -- --task "Create a hello world Node.js script"
```

Run without `--task` to start the REPL:

```bash
npm start
```

Create `.env` in the project root:

```bash
MELA_TOKEN=sk_your_key_here
```
